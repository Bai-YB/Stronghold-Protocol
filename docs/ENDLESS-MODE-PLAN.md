# 无尽模式实施计划

**开发基线：** Stronghold Protocol v0.3.3（第二期下半）<br>
**范围：** 本地实现与验证；不包含线上部署。

## 流程

- 大厅提供独立无尽入口；服务端固定终极模拟和第二期下半，禁用测试房及改变战斗数值的插件。
- 使用同盟房间和四席位上限，支持邀请、AI 补位、准备、重连和观战；以开局席位数锁定排行榜档位。
- 正常 14 关结束后，若满足隐秘核心条件先完成隐秘核心；通过后自动展示短过渡并进入无尽。普通房间保持原流程。
- 无尽对局从服务端模拟开始，使用独立的轮次计数、随机种子和检查点；常规段结算只记一次。

## 无尽规则

- 每周期 7 回合，前 6 回合普通战斗，第 7 回合 Boss；第 28 回合起每隔一个 Boss 周期出现双 Boss。
- 以 `x = 无尽回合 - 1`、`k = floor(x/7)` 计算公开成长：生命 `(1 + .12x + .004x²)(1 + .06k)²`，攻击 `1 + .045x + .0006x²`，防御 `1 + .02x`，移速 `min(1.30, 1 + .003x)`。每名博士的计划敌数为 `40 + 2x`，120 以上的溢出转为生命倍率。
- 控制时长减免从 10% 起，每周期增加 5 个百分点；普通敌人最高 60%，Boss 最高 75%。法抗每周期增加 3，新增部分最多 35，最终值不超过 80（原生更高值保留）。公开词缀轮换且不连续重复。
- Boss 击败补给按存活人数分配；博士生命归零后永久淘汰，回血不复活；全队淘汰结束挑战。Boss 超时逐步扣血，不以时间直接判负。
- 进入及每次 Boss 胜利后提供三选一增益/代价协议，持续一个周期；30 秒未选由服务端选择通用协议。
- 无尽层数不设上限，普通模式仍封顶 999；无尽 Boss 关闭单次 30 万伤害取消规则。

## 排行榜

- 单/双/三/四人榜按开局席位数归类，过滤纯真人与含 AI；至少完成一个无尽回合才公开。
- 服务端记录唯一对局 ID、规则版本、队伍摘要、完成回合与进度；按完成回合数、进度、用时排序。
- 每回合保存检查点、结束幂等追加日志并原子压缩快照；客户端不提交成绩。

## 实施与验收

按房间、循环/成长、Boss/生命/协议、持久榜/UI、数值与性能验证的顺序实现。公式检查、自动模拟和真人试玩分别报告；未完成的联机试玩不以模拟代替。
