# 无尽模式验证记录

**范围：** 本地自动检查；未部署线上。

## 已通过

- `node --test`：8 项通过、0 项失败，1 项项目既有训练守卫用例按说明跳过。
- `node --check`：`server/`、`shared/`、`public/js/` 和 `test/` 下的 JavaScript 文件全部通过。
- 公式采样覆盖无尽第 1、7、14、28、42 回合；第 10,000、1,000,000 回合的成长结果保持有限。
- 回归检查确认普通战斗叠层停在 999，无尽战斗可从 999 增至 1000；双 Boss 使用独立血池；第 28 回合生成两名不同领袖；排行榜检查点、幂等终结、AI 筛选、重启恢复和损坏日志尾部保留均有自动用例。

## 普通波次自动采样

通过服务端 `Battle` 引擎运行了 576 场独立普通波次：4 组固定八干员阵容（物理、法术、控制、混合）、1/2/3/4 席位参数、100/350/999 层、固定种子 11/29/47，以及第 7/14/28/42 回合。阵容按正常棋盘路线分配位置，并按阵容成员数计算盟约是否激活。运行中没有非有限数值或模拟器内部错误。

该采样**不是完整无尽对局或平衡通过结论**：每个样本从静态阵容直接开始，没有模拟前 14 关积累的装备、策略、资金及协议选择；席位数对普通波次本身不改变单博士战场，所以席位维度会重复同一普通战斗场景。部分固定阵容在高回合出现大量漏怪或波次超时，说明这组静态样本不能代表成熟对局，也不能据此把当前参数标为已平衡。

另外运行了 36 组连续第 1–6 回合压力样本（4 阵容 × 3 层数 × 3 种子，满血 28 点、未配置装备/策略/协议，也没有玩家主动操作）。其中只有法术阵容、999 层组的 3/3 样本活到第 7 回合；其他组多在第 3–4 回合淘汰。该结果明显偏严，必须在加入完整第 14 关成长、合法装备/策略组合和人工技能操作的连贯模拟中复核后再调参；不能把这组简化模型当作正式难度结论。
