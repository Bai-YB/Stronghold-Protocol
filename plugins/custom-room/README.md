# 自定义对局规则

这是单独的大厅“自定义对局”入口使用的房间规则插件，适配 Stronghold Protocol 0.3.x 的插件 API 1。

- 房主可将席位设为 2–20，初始为 8。
- 房主可打开“选择不限时”；它只取消策略与机变卡牌选择阶段的倒计时。
- 创建后点击房间顶部的“插件 ×N”标记打开插件面板，在“自定义对局规则”一行调整这两个选项。
- 普通“创建同盟”仍使用原来的四席与官方计时。
- 自定义对局沿用合作房间的公共干员池和轮流选择。机变阶段会把存活玩家随机分成最多四人的小组；每组使用相同的六张候选牌，但各自独立选择，同一组内不能重复选，标记为团队效果的牌只作用于本组。
- 联防阶段只要有漏怪且至少一名玩家完美通关就会开启。完美通关玩家随机组成每组最多两人的小组；奇数时最后一人单独成组。各组独立迎战分到的漏怪，多组之间尽量均分。
- 普通四人同盟的机变与联防规则保持不变。

插件只声明设置，不含脚本或可执行代码。服务器端需要同步安装本工作副本里的宿主适配；玩家使用同版本客户端进入房间。

维护者检查：`node tools/plugin.mjs check custom-room --strict`，再运行 `node tools/plugin.mjs pack custom-room --zip`。
